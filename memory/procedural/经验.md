# 经验.md

这个文件夹是 L4 程序性记忆：每干完一件事，把"下次怎么做/踩过什么坑"写回这里。
人和智能体都能直接读改 —— 这是自我进化那一层，所以不放进数据库。

## 怎么用

- 命令行里：`/exp <主题> <经验正文>` 追加一条。
- 开工时内核会自动把这里的「标题 + 摘要」注入上下文；需要细节就自己 `read_file` 读正文。

- (2026-09-27 22:20) 本地模型（Qwen3 GGUF 走 llama.cpp）会把工具调用以文本 `<tool_call>{...}</tool_call>` 吐出，不是结构化字段；适配层要把它翻译成结构化调用，否则内核收不到。
- (2026-09-28 12:50) MCP 客户端不必依赖官方 SDK：stdio 上就是「换行分隔的 JSON-RPC 2.0」。握手三件事：`initialize`（带 protocolVersion/clientInfo）→ 收 `serverInfo` → 发 `notifications/initialized`；之后 `tools/list`（可能分页，认 `nextCursor`）、`tools/call`。服务端的反向请求（如 `roots/list`）要礼貌回绝，否则会阻塞读循环。
- (2026-09-28 12:52) 给工具定权限级别时，**兜底要放在最严**：分级表没登记、元数据也没声明的工具一律按 danger。这样"漏网工具"不会因为忘了登记而偷偷放行——宁可多点一次确认，不可静默越权。
- (2026-09-28 12:54) 路径沙盒必须用 `realpath` 后再比前缀，否则 `../` 和符号链接能绕出去；比前缀时要给根补上路径分隔符（`root + "/"`），否则 `/tmp` 会误放 `/tmpfoo`。
